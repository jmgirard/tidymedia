# M076: The R version the package actually needs

**Status:** done (2026-08-27, PR #80 https://github.com/jmgirard/tidymedia/pull/80)

**Goal:** DESCRIPTION declares an R version floor derived from a measurement of the package's own code, its shipped help-page examples, and its declared dependency floors, rather than from silence.

**Outcome:** `DESCRIPTION` gains `Depends: R (>= 4.1.0)`, the package's first declared R version. `data-raw/r-floor.R` measures it from two inputs and prints both with their maximum: (a) the R-version-gated syntax in the shipped surface, counted from `getParseData()` terminal tokens `PIPE` and `'\\'` — never a regex over source text, so roxygen comments and strings cannot count — over `R/*.R` and over `man/*.Rd` examples extracted by `tools::Rd2ex(commentDontrun = TRUE, commentDonttest = TRUE)`, which enforces AC1's `\dontrun`/`\donttest` exclusion in the extractor rather than in a pattern; and (b) each versioned `Imports` floor version's own `Depends: R`, read from that exact version's DESCRIPTION fetched from CRAN (Archive, then current contrib) and untarred one file at a time. Measured: (a) 4.1.0, from 50 native pipes in the running examples and none in `R/`; (b) 3.5.0 (`rlang 1.1.0`); maximum 4.1.0. `R-CMD-check.yaml` gains `{os: ubuntu-latest, r: '4.1.0'}` — the exact version, never a moving label — which reports `Status: OK` on R 4.1.0 (2021-05-18), confirming both that `setup-r` supplies that build for the current image and that every dependency resolves there. `NEWS.md` gains a `## Requirements` section stating the floor.

**Decisions:** milestone-local — what the floor was and was not measured against: one Ubuntu job at 4.1.0 on the PR; nothing between 4.1.0 and 4.5.3 (the concrete `oldrel-1` of the day), and no dependency pinned to its own declared floor, which is M077. D053's "not measured" clause was amended to record that M076 closed the `Depends: R` half.

**Review:** three-lens fan-out. Blame-history: no findings. Prior-review: no PR threads exist in this repo, so the archive was the only surface; it found two of M074's carried rough edges reappearing in the sibling script. Diff-bug independently reproduced both legs and got identical numbers. Fourteen candidates; seven fixed at the gate — wrong `man/` locations (an extracted-file line printed under the `.Rd` name), an unbounded `R` in the `Depends` regex that returned another package's version, a benign download warning read as failure, an unversioned non-base import dropped as "base/recommended", `regmatches` over a different string than `regexec` matched, a dead assignment, and NEWS implying breakage the measurement did not find. Five deferred to the `Imports`-floors candidate row (P1 the 1000-byte download heuristic, P2 the existence-trusting reuse short-circuit, F9 `R (> x)`, F11 `\dontshow`, F8 a shadowed `sub`). Nothing tripped the return floor.
