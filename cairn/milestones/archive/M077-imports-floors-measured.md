# M077: The nine other Imports floors, measured

**Status:** done (2026-08-28, PR #81 https://github.com/jmgirard/tidymedia/pull/81)

**Goal:** Every version floor DESCRIPTION's `Imports` field declares is exercised against the version it names, so each floor states what was measured rather than what was assumed.

**Outcome:** `rlang` moves `(>= 1.1.0)` → `(>= 1.2.0)`, the one declared floor the package could not run on: `R/` calls `rlang::check_string()`, `check_bool()`, `check_number_whole()` and `check_number_decimal()` in 132 places and rlang first exports all four in 1.2.0, so on 1.1.0 every verb aborted at its own front door (1528 failures). The other eight stand. `data-raw/imports-floors.R` measures them: it reads the floors by `read.dcf`, reconciles them against the runtime closure's own requirements (moving a floor a closure member outranks, holding back a harness package no user installs), orders installs by the `LinkingTo`/`Imports` edges among the pinned set so `archive` and `purrr` compile against the *pinned* `cli` headers, drives `R CMD INSTALL` directly so a build error is recorded verbatim, and runs the suite in a fresh `Rscript` whose first `.libPaths()` entry is the pinned library. The load-bearing control is provenance, not version: per pinned package it asserts the version AND the directory resolved, before anything loads and again over `loadedNamespaces()` after the suite — the user library holds current releases, so a version check alone cannot catch a failed pin. Both media binaries are asserted on `PATH`, and the pinned run's skip count must equal the baseline's. `--baseline`, `--only`, `--repair` (AC3's CRAN Archive walk) and `--walk` modes; `TM_LIBROOT` persists libraries, its reuse guarded by re-reading the installed `Version`; `TM_RUN_TIMEOUT` bounds each child. Measured on `rocker/r-ver:4.4.3` (R 4.4.3, Ubuntu noble, aarch64) under colima, because R 4.5 hid `Rf_findVar`/`ATTRIB` and dropped `SET_FORMALS`/`SET_CLOENV`/`PRVALUE`, so six floors do not compile on the host's 4.6.1 at all. Baseline and pinned identical file for file: **6120 passing, 0 failing, 22 skipped over 66 files**. `NEWS.md` states the fact under Requirements.

**Decisions:** D055 (promoted) — what was run against each floor, and the four things that were not: direct `Imports` only with siblings current; two harness packages held back (`testthat` 3.1.10, `furrr` 0.3.1) so the floors could load; three timeout-fixture files excluded from both runs, so nothing the timeout surface does was exercised; no floor run alone, on one OS. Milestone-local: three gated criterion amendments — measuring under an older R in a container rather than moving six floors to 2026 releases; AC4 carving out the held-back harness; AC2/AC4 carving out the three wedging files.

**Review:** three-lens fan-out; the harness re-run end to end at review and again after the gate fixes, reproducing the measurement exactly. Twenty-two candidates. Five fixed at the gate: D055 claimed a disclosure it did not carry (the `-Wno-error=format-security` the measurement appends, now stated); D055's "pinned at the declared 1.1.0" was unreproducible from the committed harness, whose reconciliation would raise it to the 1.1.7 `vctrs` requires (now said, with 1.1.7 equally short of the exports); the closing report called a moved pin a declared floor; `install_pin` passed `env=` unquoted where `run_child` quotes; and the `sub()` shadowing M076's review named recurred. Two rejected with reason (NEWS's deliberate D-entry split; in-session criteria audits, disclosed at the time). Fifteen deferred — all in the developer-only sweep scripts — and, rather than extending the `Imports`-floors candidate row a fifth time, promoted at the §7 disposition to a bounded milestone hardening all three `data-raw` scripts. Nothing tripped the return floor.
