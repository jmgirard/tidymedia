# M079: The floor harness measures what it reports

**Status:** done (2026-08-28, PR #83 https://github.com/jmgirard/tidymedia/pull/83)

**Goal:** Make the four `data-raw` floor-measurement scripts fail loudly where they today return a number nobody measured, and delete the two modes whose bugs are cheaper to remove than to fix.

**Outcome:** `is_package_tarball()` — a size floor plus `untar`'s LISTING plus its EXIT STATUS — is the one test of "is this a package tarball" in `imports-floors.R`, `withr-floor.R` and `r-floor.R`, on the cache branch as well as the download branch; a refused file is unlinked and refetched. `install_pin()` writes a `tidymedia-floor-pin.dcf` stamp recording what each entry was linked against, and `can_reuse()` needs the `Version` and that stamp; `--no-test-load` is gone from both install sites. Three DESCRIPTION readers abort instead of guessing: `withr-floor.R`'s `regexec` on an `Imports` with no `withr (>= )`, `r_floor_of()` on any comparator but `>=`, and `UNVERSIONED_OK <- c("tools", "utils")` in place of `priority = c("base", "recommended")` in both scripts. `archive_versions()` refuses a failed Archive listing, an empty CRAN database and a failed `available.packages()`; `reconcile()` aborts on non-convergence in `MAX_ROUNDS`; the per-file table prints its `error` column; `timeout-bound.R`'s summary reports each case's own `observed elapsed` and carries the driver stopwatch beside it, labelled. `HOLDBACK_SET <- c("testthat", "furrr")` replaces "everything outside the runtime closure", and a requirer outside both stops the run by name. `--repair` and `--walk` are deleted, flags and code paths and usage lines. `data-raw/floor-probes.R` is new: 46 probes, one per input class the scripts distinguish, sourcing each script under a `TM_DEFS_ONLY` guard and staging modified DESCRIPTIONs as symlink roots so nothing writes to the repo.

**Decisions:** M079-D1 (milestone-local) — the harness refuses rather than reports, and two of its modes are gone. Five parts: the two deleted modes and why walking a version forward is a decision not a measurement; the named rather than derived holdback set; "installs" now meaning "loads"; the literal unversioned carve-out; M077 F17 measured (`R CMD INSTALL -l '~/tm floor probe/lib'` installs at status 0 — R expands the tilde itself). D053, D055 and D056 stand untouched and no declared floor moved.

**Review:** One round, three fresh-context lenses. All seven criteria verified with fresh evidence; no defect return, no amendment return. The probe harness was proven able to fail before its green was trusted — three rounds of planted defects in the scripts it measures turned 21, then 3, then 3 probes red, each in the probe that claims that class. AC1's `withr-floor.R` clause and AC4's `elapsed(s)` clause were measured directly rather than through the harness, because the harness does not cover either. Blame-history and prior-review lenses: no findings. Diff lens: fifteen, five fixed at the gate — a claim that D055 quotes a `TOTALS` line it does not quote (superseded by an appended work-log line, not edited); `withr-floor.R` reading any `download.file()` warning as failure and unlinking a good tarball; probe A6 failing spuriously on a host whose `untar` uses R's internal reader; `--offline` still fetching nine DESCRIPTIONs through `r-floor.R`; and H1 having no positive control (H0 added). Ten deferred to one ROADMAP candidate row grouping them as findings about the INSTRUMENT rather than the floors it measures. Nothing retired at hygiene; M079's lesson folded into the M074 line.
