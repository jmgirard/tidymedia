# M097: A remembered binary location lives where CRAN policy sanctions

**Status:** done (2026-09-01, PR #102 https://github.com/jmgirard/tidymedia/pull/102)

**Goal:** Move `set_program()`'s write path and `find_program()`'s read path to `tools::R_user_dir("tidymedia", "config")` — the only user config location CRAN policy sanctions — without losing a location a user set before the change.

**Outcome:** Three internals in `R/program_management.R`: `tm_config_dir()` (`tools::R_user_dir("tidymedia", "config")`), `tm_legacy_config_dir()` (the single `rappdirs::user_config_dir("tidymedia", "R")` call in `R/`, so the legacy layout is computed by the library that wrote it) and `tm_config_file(program, dir)`. `set_program()` writes `<program>_location.txt` under the new dir; `find_program()` reads the new file and, only when none EXISTS, the legacy one — a stale new file is never bypassed for a valid legacy one (kept at review, documented instead of changed); nothing is migrated. `rappdirs` stays in `Imports` (D055's floors untouched). `NEWS.md` "Configuration" entry; `?find_program` and `?set_program` name the directory, the file and the pre-0.2.0 fallback. Tests in `test-program-management.R`: AC1 path EQUALITY over every file written under a redirected `R_USER_CONFIG_DIR` (containment passes against the old code, since rappdirs honors the envvar too); AC2 four programs x three file states under `PATH = ""` with distinct executable stubs (`.bat` on Windows) at the two paths, the legacy library redirected by a `rappdirs::user_config_dir()` mock whose return value records its arguments; AC3 the stale-location warning from the legacy path; `test-nvenc-memo.R`'s write redirected by the envvar instead of a rappdirs mock that would have redirected nothing.

**Decisions:** none cross-cutting. Milestone-local: a silent legacy read (no migration message); the fallback keys on file existence, not validation failure, because the file the user wrote last is authoritative and the stale branch already warns.

**Review:** Three-lens fan-out (user-facing tier). Blame-history and prior-review lenses: zero findings (the PR-comment surface is empty; M67/D044's memo discard in `set_program()` preserved). Diff-bug lens: nine findings.
