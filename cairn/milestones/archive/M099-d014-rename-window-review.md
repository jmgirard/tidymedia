**Status:** done (2026-09-01, PR #101 https://github.com/jmgirard/tidymedia/pull/101)

**Goal:** Decide, for each of the four candidate API changes D014's clean-break policy holds open, whether it ships now or is declined permanently — while a rename is still free of a deprecation cycle.

**Outcome:** Two renames shipped under D014's clean break, no `lifecycle` shim. (d) `has_nvenc()` / `nvenc_encoder()` / `tidymedia.nvenc_encoders` → `has_hardware_encoder()` / `hardware_encoder()` / `tidymedia.hardware_encoders` by word-boundary replacement over `R/`, `tests/`, `vignettes/`, `_pkgdown.yml`, `data-raw/` and `DESIGN.md`; D044's option-before-memo read order (`R/ffmpeg.R`) and D050's worker carry (`R/timeout.R`) unchanged under the new string; internal `nvenc_available()` / `check_nvenc_available()` left for M100. Declined for good: the `NULL`-reading unification, a per-verb `check_tracks =`, a per-call `timeout =` — each ROADMAP row now carries a per-row `jobs`-column reopening shape under a post-0.2.0 deprecation cycle. `test-d014-rename-window.R` runs the AC1 sweep: formals over `getNamespaceExports()` (`audio_input` on exactly four, `audio` on two, `audio_stream` on 18, `check_tracks`/`timeout` on none), the hardware-pattern export grep, and the option seam. The `timeout-valid-baseline.rds` cell recorded as `has_nvenc` is read under the new key in `helper-timeout-sweep.R`, guarded by a `stopifnot` that fails once the blob is re-recorded; the `data-raw/` generators set both option names so `ref = NULL` and pinned-ref runs both work. `?audio_stream` gained "The bare name `audio` is not an index"; `man/nvenc_encoder.Rd` became `man/hardware_encoder.Rd`; two Breaking-changes entries in `NEWS.md`.
