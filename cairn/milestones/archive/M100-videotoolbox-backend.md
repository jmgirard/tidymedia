# M100: Hardware encoding is a backend vocabulary, and videotoolbox is the second member

**Status:** done (2026-09-02, PR #104 https://github.com/jmgirard/tidymedia/pull/104)

**Goal:** Generalize the nvenc-only hardware surface into a backend vocabulary and ship videotoolbox as its second member, so hardware encoding works on Apple hardware.

**Outcome:** `hardware_backend_families()` is the two-key table (nvenc h264/hevc/av1, videotoolbox h264/hevc) and `hardware_backends()` reads off it. `hardware_encoder(codec, hardware)` maps a family and a backend to an encoder name and is the one site refusing a pair the table lacks, with `call` threaded so the verb the caller typed is blamed; `codec_family()` stays a backend-free inference and gained a `prores` branch so that refusal can name the family. `nvenc_available()`/`check_nvenc_available()` became `hardware_encoder_available()`/`check_hardware_available()`, the front-door gate widened from `identical(hardware, "nvenc")` to backend-set membership, and `hardware = c("none", "nvenc", "videotoolbox")` reached the 16 exported verbs and `resolve_hw_encoder()`. Both exported helpers take a required `hardware =` (D079); `tidymedia.hardware_encoders`, the option seam above the session memo, is unchanged. `test-hardware-backends.R` adds the vocabulary sweep, the table-iterating compile assertions, both refusals, both probe routes in both directions, the per-backend fallback, and the first hardware path this suite can execute for real — a videotoolbox encode behind a one-frame-encode skip.

**Decisions:** D079 (both helpers take a required `hardware =` over the backend set only; `"none"` refused). Milestone-local: the (family, backend) refusal is sited in `hardware_encoder()` once, not in `codec_family()` (RR07 R4); the two helpers and their doc/probe sweeps are excluded from `nvenc_hardware_exports()` by `nvenc_hardware_helpers()` (RR07 R8); `prores` is a family the package infers and no backend's table holds, so both backends refuse it; the internals serving both backends are renamed while the nvenc-named test files and helpers keep their names.
