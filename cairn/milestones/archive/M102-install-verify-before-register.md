# M102: `install_on_win()` verifies the archive and the unpacked programs before it registers anything

**Status:** done (2026-09-02, PR #106 https://github.com/jmgirard/tidymedia/pull/106)

**Goal:** `install_on_win()` verifies the archive it downloaded against the digest its source publishes and confirms the programs the package needs were unpacked before it writes any remembered location, and every failure on that path past the front-door argument checks returns `FALSE` or carries a `tidymedia_*` condition class.

**Outcome:** The installer now fetches `<download_url>.sha256` before it unpacks, parsing a bare digest, a `sha256sum` line or a `SHA256(<file>)= <hex>` line case-insensitively, and compares it against `digest::digest(file = TRUE)`; a new `archive_checksum =` argument supplies a digest for any source and suppresses the sidecar fetch, with `check_sha256()` refusing a non-64-hex value at the front door. Four classed refusals replace what were unclassed aborts or silent successes: `tidymedia_download_unavailable`, `tidymedia_checksum_unavailable`, `tidymedia_checksum_mismatch`, `tidymedia_archive_unreadable`, `tidymedia_program_not_extracted`. Registration is gated on `tm_extracted_programs()`, which intersects `archive_extract()`'s returned file list with `bin/<program>.exe` rather than reading the disk, so a previous install's leftovers no longer count as produced; `ffmpeg`/`ffprobe` are required, `ffplay` optional with a message. `tm_close()` closes libarchive's connection so the failed download is unlinked on Windows. `digest (>= 0.6.37)` joins `Imports` (D081); `rlang::check_string()` now covers `install_dir` and `download_url`; two 7z fixtures and `data-raw/corrupt-archive-fixtures.R` cover libarchive's two failure shapes, pinned by `*.7z binary`. AC6's test walks `body(install_on_win)` and asserts every `return()`/`cli_abort()` node is classed or literal.

**Decisions:** `archive_checksum` defaults to `NULL` — the absence sentinel (D016, D022), not a member of the set the argument ranges over, so D079's antecedent is not met and the unverified caller-named path pays with a message rather than a silent skip. Cross-cutting: D081 (`digest` in Imports).
