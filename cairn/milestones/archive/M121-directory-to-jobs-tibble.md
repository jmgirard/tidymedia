# M121: A directory becomes a jobs tibble

**Status:** done (2026-09-10, PR #125 https://github.com/jmgirard/tidymedia/pull/125)

**Goal:** One export turns a directory of media files into the jobs tibble `ffm_batch()` takes, so the batch story does not start with a hand-rolled `list.files()`.

**Outcome:** `ffm_jobs(directory, type, extension = NULL, recursive = FALSE)` (`R/ffm_jobs.R`), a wrapper over the internal `tm_ffm_jobs(..., call)` per D087. `type` ranges over the closed `media_types()` set (`"video"`, `"audio"`, `"image"`) and takes no default (D079); `extension` narrows within `media_extensions(type)`, dot and case insensitive. The body is `list.files(pattern, ignore.case = TRUE, full.names = TRUE)` filtered by `file.exists() & !dir.exists()`, then `normalizePath()`, returning a tibble whose only column is `input`; zero matches abort rather than return zero rows. `check_string(type)` runs before `rlang::arg_match()`, which silently reduces any permutation of the full value set to its first element. Seventeen refusal branches, all blaming `ffm_jobs`. `vignettes/workflow.Rmd:40` and `vignettes/metadata.Rmd:123` call it in place of `list.files()`; `_pkgdown.yml` row; the `NEWS.md` entry names which six of the fifteen `*_batch()` verbs take the table unaltered. Disclosed limits, each a candidate item on the `ffm_jobs()` row: on Windows a dangling symbolic link can still be a row (f), since `file.exists()` is TRUE for it there, and `test-ffm-jobs.R`'s two dangling-link blocks are `skip_on_os("windows")`; visibility is dot-prefix only on every platform (g); `recursive = TRUE` follows a directory symlink, so a row can name a file outside `directory` (h).

**Decisions:** D092 — the `ffm_*` prefix covers the jobs-table functions around the runner, not only command assembly.
