# M136: The batch re-encoding functions take `quality` as an argument and as a jobs column

**Status:** done (2026-09-18, PR #140 https://github.com/jmgirard/tidymedia/pull/140)

**Goal:** A batch caller sets the encoder's own quality number for the whole batch or per row.

**Outcome:** `quality = NULL` after `fallback` on `standardize_video_batch()`, `format_for_web_batch()`, `anonymize_video_batch()`, `crop_video_batch()`, `segment_video_batch()`, `separate_audio_video_batch()`, `compare_videos_batch()` and `picture_in_picture_batch()`. A numeric `quality` column of `jobs` overrides it per row. An `NA` cell keeps that row's encoder default whatever the argument says (D022). `check_batch_quality(jobs, quality, codec_rows, hardware)` in `R/ffmpeg.R` checks both forms in one call at each verb's front door, above `check_hardware_available()` (D036). The column must be numeric or all-`NA` logical and must not hold `NaN`. The argument's type is checked even when a column overrides it. Each non-`NA` value takes M135's `check_quality()` against `intended_encoder()` over that row's resolved codec, and a `"copy"` cell bypasses the family lookup. `check_batch_cell()` names the row for a column cell and for an argument refused by one row's codec cell, and names none for a bad argument value. `segment_video_batch()` also refuses a cell on a `reencode = FALSE` row. `separate_audio_video_batch()` builds the reshaped `quality` column after the check, with the value on each input's video row. `batch_quality_param()` in `R/task-doc.R` writes the 8 help entries, and NEWS names the column. Tests: `test-quality-batch.R` (52 verb-by-encoder pairs, both range ends, the argument form, NA over the argument, refusals against a probe counter), `test-quality-batch-col.R` (the helper directly), and the two census pins moved by the 40 new cells.

**Decisions:** M136-1, one checker for both forms with the row-locator rule written once, over a per-verb sweep beside each codec sweep.

**Review:** three-lens fan-out. The blame-history and prior-review lenses found nothing. The diff-bug lens reported 6 findings, all logged. Five were fixed now, each with a test: a wrong `quality` argument was skipped when a column was present. A `NaN` cell read as the NULL sentinel because `is.na(NaN)` is TRUE. An argument refused for one row's `"copy"` or `NA` codec cell named no row. No test put the argument and the column in one call. The all-`NA` non-numeric locator case was undocumented. One was rejected: the reshaped `quality` column is built after `reject_duplicate_outputs()` while `audio_stream` is built before it, a deliberate and commented placement over a function that returns its table unchanged. Fresh check 0/0/0 and 16309 tests passing on the fixed head. CI: 8 workflow checks green. The codecov patch (88%) and project statuses reported red and were merged past as advisory. No LESSONS line. At hygiene: the review's `document()` no-diff ran under roxygen2 8.0.0 against the 8.1.0 pin (LESSONS M128), so `man/` and `NAMESPACE` were regenerated in a scratch copy with the pin lowered, and they are identical to the merged tree.
